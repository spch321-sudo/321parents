# 屬靈父母手冊 App（v2.3.2610291440）

國度321空中團契・落實321。認領、生育、養育、教育、衍育，五週走完五育。

## 上傳方式（GitHub Pages）

把這個資料夾裡的**所有檔案**平放在 repo 的根目錄（不要放進子資料夾），覆蓋舊檔後推上去。
1～10 分鐘後 GitHub Pages 生效；已經安裝在手機主畫面的舊版會自動換成新版（朗讀、打字、小智回答中不打斷，空閒時才換）。
手機一時還是舊畫面，到「設定 → 版本與更新」按「檢查更新」或「強制更新」。

## 檔案

| 檔案 | 用途 |
|---|---|
| index.html | 主程式（ES5，繁體介面字串內嵌） |
| content.zh.json／content.zs.json／content.en.json | 手冊內容（繁／简／英） |
| lang-zs.json／lang-en.json | 简體、英文介面字串 |
| media.js | 美圖配樂、AI 配樂提示、錄音／卡片影片／自拍影片、我的作品、小智寫祝福（進美圖工作室才載入） |
| card.js | 經文美圖工作室：畫卡片、版型外框、背景圖庫、Pexels、AI 畫背景（進美圖才載入） |
| play.js | 考考我：猜謎、測驗、錯題本（進入時才載入） |
| sw.js／version.json | 離線與自動更新（快取前綴 spf321-，不會動到其他 321 App） |
| manifest.json、icon-*.png、maskable-*.png、apple-touch-icon.png、favicon.png | 主畫面圖示（主視覺方圖） |

## v2.0 新功能（照 321app 技能完整移植）

- 頂列 繁｜简｜EN 三語切換、字級一鍵循環（標準／大／特大／超大）、主題（跟隨系統／淺色／深色／護眼米色）
- 逐句切分：點一句畫線（8 色、句數＋－、整段、默想、問小智、做成美圖、從這句朗讀、複製、分享、刪除），「我的畫線與收藏」
- 朗讀：Azure 真人語音 3 選 1、語速、跨段落自然帶入語、鎖屏背景播放、浮動控制列；失敗自動改用裝置語音
- 小智：全螢幕對話、回答對象 10 種（成人、青少年、兒童、慕道友、長輩、單親家長、單身、父母、夫妻、牧者同工）、慕道友信仰背景 6 種、回答長度、追問鈕、長回答收合、截斷自動接續、「憑信心禱告」規則、收藏、分享、做成美圖、朗讀
- 經文美圖：9 版型、4 尺寸、6 外框、背景圖庫、Pexels、自己的相片、AI 畫背景；小智寫祝福、配樂（詩歌庫／自選／AI 配樂提示）、錄音與影片、我的作品
- 考考我：小智照本章出題（猜謎 4 題、測驗 5 題）、錯題本（離線可複習）、最佳成績
- 操練獎章：一章的操練全部打勾就跳出獎章動畫，目錄標示 🏅
- 初信八週陪讀課程（v2.1）：課程總覽、每次 60 分鐘流程、陪讀者五原則；每週一課含本課目標、破冰問題、本週經文（和合本／BSB 自動帶入）、背誦經文（可做成美圖）、三點信息、分享討論、本週操練打勾（全勾自動完成本週）、憑信心禱告、給陪讀者的提醒、下週預告、筆記、考考我、問小智怎麼帶
- 線上聚會：晨讀、午修、晚禱（台北時間），Zoom 一鍵進入
- 自動更新：version.json 輪詢＋Service Worker；設定頁可「檢查更新」「強制更新」
- 舊版（v1）的家族名單、操練、筆記、評分會自動搬進新版
